📌 Overview

This repository contains a comprehensive financial dashboard designed to track and analyze key business metrics, including revenue, profitability, and cost of goods sold (COGS). The interactive report allows users to slice and filter data across multiple dimensions to uncover seasonal trends and segment performance.

🛠️ Tools & Technologies

* Power BI: Used for data visualization, dashboard design, and interactive filtering.

📊 Dashboard Visual

📈 Key Performance Indicators (KPIs) & Insights

Based on the dashboard visuals, the report tracks the following core metrics and breakdowns:

* High-Level KPIs:** Total Sales (118.73M), Total Profit (16.89M), Profit Margin (14.23%), and Sum of COGS (101.83M).
* Time Series Analysis:** Month-over-month tracking of Total Sales and Total Profit, highlighting a significant performance spike in October.
* Product & Geography:** Profitability breakdowns by product (with *Paseo* as the top driver) and total sales distributed across regions including the USA, Canada, France, Germany, and Mexico.
* Market Segments:** Sales distribution by sector, heavily driven by the Government (44.22%) and Small Business (35.74%) segments.
* Interactive Filters:** Built-in slicers allow users to drill down by Year (2013, 2014), Country, Product, Segment, and Discount Band.

🚀 How to Use This Dashboard

To interact with the dashboard and explore the data yourself, follow these steps:

1. Download Prerequisites:** Ensure you have [Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed on your machine. It is a free application provided by Microsoft.
2. Clone or Download the Repository:**
* Click the green **Code** button at the top right of this repository.
* Select **Download ZIP** and extract the files to your computer, or clone the repository using Git.


3. Open the File: Locate the `.pbix` file in the downloaded folder and double-click to open it in Power BI Desktop.
4. **Interact: Use the filter panes on the bottom left and top right (e.g., Year, Country, Product, Segment) to dynamically update the charts and see specific data slices.
